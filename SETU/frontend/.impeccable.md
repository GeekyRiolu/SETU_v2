# SETU frontend

Next.js (App Router, TypeScript) UI over the SETU REST API. Static-exportable,
offline-first, styled after the civic-tech aesthetic of SFLC's Free Speech
Tracker (freespeech.sflc.in) — adapted to a translator.

## Design Context

### Users
People who need to move text between the 22 scheduled languages of India and
English **where the network is unreliable, absent, or untrusted** — rural users,
privacy-conscious readers, field workers, researchers, and developers embedding
offline MT. The job: translate a sentence or paragraph, trust that it ran
locally, and see honest signals (latency, on-device, model size).

### Brand Personality
Principled, plural, grounded. A public-interest "translation commons," not a SaaS
product. Voice is calm, exact, and a little activist — it states guarantees and
then measures them. Emotional goal: quiet confidence and trust.

### Aesthetic Direction
Warm **civic print**. Light theme (daytime, document-reading, modest devices).
Paper + ink neutrals tinted warm, with a single **sindoor-vermilion** mark used
sparingly (≈10%), indigo for links, moss only for the "on-device" pill. Type
pairs **Bricolage Grotesque** (display) with **Spectral** (serif body); Indic
scripts render via the system Noto stack so it works offline. Reference:
freespeech.sflc.in (editorial headings, punchy section names, prominent CTA,
generous sectioning). Anti-reference: generic SaaS dashboards, AI cyan/purple
gradients, glassmorphism, four identical icon cards.

### Design Principles
1. **The 22 scripts are the interface.** Languages are named by their endonyms in
   their own writing systems (हिन्दी, বাংলা, தமிழ், اردو, ᱥᱟᱱᱛᱟᱲᱤ) — never flags.
2. **Honest telemetry.** Show real latency, model variant/size, and whether a
   translation ran on a trained model or passed through (stub). Never fake it.
3. **Offline is a feature, shown.** No runtime CDN/fonts; a visible engine-status
   indicator; copy that foregrounds "nothing leaves your machine."
4. **Editorial, not templated.** Asymmetric hero, a spec *ledger* (not icon
   cards), a numbered method flow, varied spacing rhythm.
5. **The tool works.** The translator console is the centerpiece and is fully
   wired to POST /translate + GET /languages + GET /models, with graceful
   offline fallback.
